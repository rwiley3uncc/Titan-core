## Networking Review

- Subnetting splits a network into smaller address ranges.
- A subnet mask identifies which bits belong to the network portion and which bits belong to the host portion.
- CIDR notation such as `/24` means the first 24 bits are the network portion.
- Smaller subnets reduce broadcast scope and can improve local network organization.

## Study Tip

When reviewing subnetting, practice converting between:

- dotted-decimal masks
- CIDR prefixes
- number of hosts per subnet
